## Judging (C unless marked)

- Demo fair, not stage pitches: Sunday Oct 11, 12:00-1:30 PM. Find your table on the
  Devpost "Tables" tab.
- 3 judges visit each table; **4 minutes per judge: 2 minutes demo, 2 minutes Q&A**.
  Absent team = 0 from that judge.
- Criteria (partly L): Application/Impact ("feasible application and/or social impact"),
  Technical Complexity, Functionality/Quality ("free of major bugs", "looks appealing"),
  Creativity, Presentation.
- Winners announced at the closing ceremony, 3:00 PM, Hamilton Hall 100.

## Rules (C)

- Submit on Devpost **by 10:00 AM Eastern, Sunday Oct 11**. One project per team.
- GitHub link required for all code written for the hack.
- Demo video required, **max 2 minutes**; no video, no judging.
- No projects developed partially or fully before hacking starts; no cross-posted projects.
- Ages 18+, US only. Recommended team size 3-4 (hacknc.com).
- AI-tool policy: ? (MLH guidance: credit AI use).
